Ummah Homes is a platform to find and list homes for sale and rent.
Houses can be listed for sale or rent. 
Roomes can be listed for rent.
Basements can be listed for rent.

The platform does not restrict users by religion. Listers decide who to accept or deny based on background checks and other valid reasons.

Amendment (2026-08-31): owner removed the earlier “for Muslims” product rule.

A webapplication, ios app and android app will be built for users to access the platform.
An admin panel will be built for the platform to manage all listings and all users.
A dashboard will be built for the admin to manage the platform and all listings and all users.

A user (name will need to be defined for a seller) panel will be built for users to create and manage their listings.
A user (name will need to be defined for a buyer/renter) panel will be built for users to monitor their listings and manage their bookings.


Inspiration: Zillow.com/ ApartmentList.com/ Realtor.com

## Restated

A hosted marketplace named Ummah Homes where people can find and list whole homes for sale or rent, and rooms or basements for rent. The platform does not encode a religious eligibility rule; listers accept or deny applicants using background checks and other valid reasons. Users would reach it via web, iOS, and Android. The owner also wants an admin panel (and an admin dashboard), a seller listing-management panel, and a buyer/renter panel for monitoring listings and managing bookings. Inspiration named: Zillow, Apartments.com, Realtor.com. Build and release in stages.
